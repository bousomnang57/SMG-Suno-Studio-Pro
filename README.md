# 🎵 SMG Suno AI Lyric Writer — Global Music Studio

An AI-powered desktop songwriting and lyric studio built with **Python 3.14**, **PyQt6**, and **Google Gemini AI** (`google-genai`). Engineered specifically for songwriting across worldwide musical genres and traditions with real-time syllable meter analysis, interactive line rewriting, rhyme detection, Suno/Udio prompt generation, text-to-speech vocal auditioning, and multi-format exporting (PDF Lead Sheet, Timed LRC, TXT, JSON).

## ⚡ Key Features

- **Polyphonic Audio Chord Synthesizer**: Pure-Python zero-latency acoustic piano & Rhodes chord tone synthesis. Audition individual chords or full progressions directly in tempo with metronome sync.
- **22 Global Hit Chord Progression Formulas**: Includes Pop Standard 4-Chords, Royal Road (Oudou), Khmer Sinn Sisamouth Golden Classic, Khmer Romvong Folk, Neo-Soul 2-5-1, Andalusian Flamenco, Latin Dem-bow, 80s City Pop, Hans Zimmer Cinematic, and 808 Trap.
- **MasterWriter-Grade Sensory & Imagery Thesaurus**: 300+ evocative poetic words, contrast oxymorons, and rhyme families across 8 sensory dimensions in both English and Khmer.
- **Real-Time Syllable & Rhythm Gutter**: Displays exact syllable counts per line in real time, color-coding rhythm cadences to help songwriters lock lyrics into musical meters and tempo bars.
- **Google Gemini Engine (Pro & Flash)**: Asynchronous background AI lyric composition, targeted line rewriting, and multi-syllabic rhyme discovery.
- **Suno v3.5 & Udio v1.5 Prompt Studio**: Live character gauges (120, 200, 350 chars), negative style filters, and meta-tag vocal cues.
- **Vocal Auditioning (TTS) & Mic Melody Scratchpad**: Audition lyrical cadence out loud and record hummed melody ideas with the built-in microphone recorder.
- **Multi-Format & DAW Production Exporter**:
  - **.mid**: Standard MIDI chord track drag-and-drop ready for Ableton Live, FL Studio, Logic Pro, and Cubase.
  - **.zip**: All-in-one production bundle with lyrics, karaoke LRC, MIDI chords, project JSON, and AI prompt sheet.
  - **.txt**: Clean lyric sheet with metadata headers.
  - **.lrc**: Timed karaoke lyric file formatted with timestamp tags computed from BPM and syllables.
  - **.pdf & .html**: Lead sheet formatted with typography, section headers, and song metadata.
  - **.json**: Structured song object with section breakdowns and syllable counts.

## 🛠️ Architecture & Technology Stack Recommendations

### Recommended Core Architecture:
| Component | Technology | Rationale |
|---|---|---|
| **GUI Framework** | **PyQt6** (Python) | Native 60 FPS performance, rich desktop OS integration, custom painter gutters, cross-platform. |
| **AI LLM Engine** | **Google Gemini 2.5 Flash / Pro** | Industry-leading multilingual understanding, poetic creativity, speed, and 1M+ token context window. |

| **Vocal TTS Auditioning** | **Windows SAPI / pywin32** | 0ms local latency, zero network dependency, reliable offline playback. |

## 🚀 Quick Start Guide

### 1. Run the Application
Open a terminal in this directory and run:
```bash
python main.py
```

### 2. Configure Gemini API Key (Optional)
1. Click **⚙️ Settings** in the top header bar.
2. Enter your Google AI Studio API key (or click the link to get a free key).
3. Select your preferred model (`gemini-3.5-flash` is recommended for high-speed, zero-quota-error lyric creation).
4. Click **Test Connection**, then click **Save Settings**.
*(Note: If no key is entered, you can still test all features using **"Load Genre Demo Track"**).*

### 3. Build a Standalone Windows Executable (.exe)
To package SMG Suno AI Lyric Writer into a single portable `.exe` file using PyInstaller:
```bash
pyinstaller --noconfirm --onedir --windowed --name "SMG_Suno_AI_Lyric_Writer" --icon "assets/logo.ico" main.py
```
The compiled executable will be located in the `dist/SMG_Suno_AI_Lyric_Writer/` folder.
